# eBay Wallet Related Products – Test Automation

## Project Overview
This project contains automated tests for validating the **Related Products feature** on the eBay product page when searching for a wallet.

The objective is to verify that:
- Related products appear on the main product page
- A maximum of **6 best seller products** are displayed
- Related products belong to the **same category**
- Related products are within a **similar price range**
- The related products section is displayed correctly

Automation is implemented using **Playwright with JavaScript**.

## Test Coverage

The automation covers the following scenarios:

3. Verify related products belong to the **same category**
4. Verify related products are within a **similar price range**
5. Verify related products can be opened successfully
